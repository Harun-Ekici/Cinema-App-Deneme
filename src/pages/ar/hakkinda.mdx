# حول CineQ

**CineQ** تطبيق حجز من الجيل الجديد لسطح المكتب والهاتف، طُوِّر بتقنيات حديثة لإلغاء طوابير شباك تذاكر السينما والمقصف.

<CanliRozet client:load etiket="Tauri v2 + Astro + Svelte 5" />

## معلومات المطوّر

- **المطوّر:** Harun Ekici
- **القسم:** تكنولوجيا الحاسوب
- **الجامعة:** جامعة إستينيا
- **المقرر:** MYO063 برمجة الهاتف المحمول

## البنية والتقنيات

- **Tauri v2 (Rust):** بنية تشغيل آمنة ومحلية وخفيفة لسطح المكتب.
- **Astro:** مولّد صفحات ثابتة محسَّن يدعم أكثر من إطار عمل.
- **Svelte 5 Runes:** واجهة تفاعلية وإدارة حالة (`$state`، `$derived`).
- **دعم React:** استخدام مباشر لمكوّنات React داخل MDX.

## صفحات التطبيق

- **استكشاف (`/`):** الأفلام المعروضة والقاعات واختيار العرض
- **المقصف والسلة (`/sepet`):** طلبات الفشار والمشروبات ومجموع التذاكر
- **تذاكري (`/biletlerim`):** التذاكر المشتراة ورموز التحقق
- **الملف الشخصي (`/profil`):** تفضيلات المستخدم وتبديل السمة وصفحات المعلومات
