# شرایط استفاده

**آخرین به‌روزرسانی:** ۹ اکتبر ۲۰۲۶

با استفاده از این برنامه، شرایط زیر را می‌پذیرید.

## ۱. پروژه آموزشی

CineQ یک پروژه دانشگاهی است که برای درس **MYO063 برنامه‌نویسی موبایل دانشگاه ایستینیه** ساخته شده است. هدف تجاری ندارد و فیلم‌ها، سانس‌ها و خرید بلیت نمایش‌داده‌شده شبیه‌سازی هستند.

## ۲. شرایط خدمت

رزروها و سفارش‌های بوفه که در برنامه ساخته می‌شوند هیچ تعهد مالی واقعی ایجاد نمی‌کنند.

## ۳. مالکیت فکری

طراحی رابط، لوگو و کد نرم‌افزار متعلق به تیم پروژه است. پوسترها و لوگوهای فیلم که برای معرفی استفاده شده‌اند متعلق به صاحبان حقوق آن‌ها هستند.
